# ЯТО — приложението

Живее в `/app/`. Чист HTML, CSS и JavaScript — **без build стъпка, без npm, без нищо за инсталиране.**
Променяш файл, качваш го в GitHub, готово.

**Адрес, след като е качено:** `…github.io/yatto-site/app/`

---

## Какво може засега

| Екран | Какво прави |
|---|---|
| **Влез** | Вписване с имейл, без парола. Получаваш линк и си вътре. |
| **Начало** | Обратно броене до следващото ти състезание + състояние на отбора и транспорта |
| **Състезания** | Календар с филтри. Виждаш кой отива и кой търси отбор. |
| **Детайл** | Инфо · Кой отива · Пътуване. Оттук казваш „Отивам" и „Търся отбор". |
| **Пътуване** | Предлагаш кола със свободни места и дял от разхода, или се качваш при някого. |
| **Зали** | Списък със залите, филтър по град |
| **Профил** | Име, град, зала, дивизия, Instagram, профил на силата |
| **Админ** | Само за теб: добавяш и триеш състезания, без да пипаш база данни |

**Чат няма нарочно.** Свързването става през Instagram. Така никой не чака отговор от нас, няма спам за модериране и няма чужди съобщения, които да пазим. При един човек екип това не е компромис, а оцеляване.

## Пускане — веднъж, около 15 минути

### 1. Създай базата
1. [supabase.com](https://supabase.com) → **New project** → име `yatto`, регион **Frankfurt**
2. Запиши си паролата на базата някъде безопасно
3. Отвори **SQL Editor** → **New query**
4. Отвори файла `app/schema.sql`, копирай **всичко** и го залепи
5. **Run**

Това създава таблиците, правилата за достъп и петте зали.

### 2. Свържи приложението
**Project Settings → API**, копирай:
- **Project URL**
- **anon public** ключа

Отвори `app/config.js` и ги попълни:

```js
export const SUPABASE_URL = "https://abcdefgh.supabase.co";
export const SUPABASE_ANON_KEY = "eyJ...";
```

> `anon` ключът е публичен по замисъл — стои в кода на всеки Supabase сайт.
> Защитата идва от правилата в `schema.sql`, не от криенето на ключа.
> **Никога** не слагай тук `service_role` ключа.

### 3. Кажи на Supabase откъде идва приложението
**Authentication → URL Configuration**:
- **Site URL:** `https://lumoscreativeagency.github.io/yatto-site/app/`
- **Redirect URLs:** добави същия адрес

Без това линкът от имейла ще води наникъде.

### 4. Направи себе си админ
1. Влез веднъж в приложението — така се създава профилът ти
2. Supabase → **Table Editor → profiles** → намери своя ред
3. Сложи `is_admin` = **true** и запази

Чак тогава се появява екранът **Админ**.

> Никой не може да се направи админ сам — в базата има правило, което го пази.

### 5. Въведи първите състезания
Админ → попълваш формата. **Проверявай датите два пъти.** Грешна дата е по-лошо от липсващо състезание.

## Как се променя нещо

Всеки екран е отделен файл. Няма скрити зависимости.

```
app/
  config.js          ← двете ти стойности
  app.js             ← общи функции: вписване, дати, заглавка, долна лента
  app.css            ← всички стилове
  index.html         ← Начало
  competitions.html  ← списък
  competition.html   ← детайл (три таба)
  gyms.html          ← зали
  profile.html       ← профил
  admin.html         ← само за админ
  login.html         ← вписване
  schema.sql         ← базата
  supabase.js ← библиотеката, сложена локално нарочно
```

**Защо библиотеката е локална:** ако се зареждаше от чужд CDN и той падне, приложението ти пада с него. Този файл не се пипа.

## Локален преглед

Двоен клик върху `index.html` **няма да работи** — браузърите не пускат модули от файл.
Ако искаш да го гледаш на компютъра си, отвори терминал в папката и пусни:

```bash
python3 -m http.server 8000
```

После отвори `http://localhost:8000/app/`.

Иначе просто гледай качената версия — тя работи нормално.
